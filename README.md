# Student-Management-SQL-Project

## 📌 Project Overview

This project focuses on analyzing student data using MySQL. It demonstrates SQL queries to retrieve, filter, sort, and analyze student information, including marks, attendance, fees, departments, and admission dates.

## 🎯 Objectives

* Retrieve and filter student records.
* Analyze student marks and attendance.
* Calculate average, maximum, minimum, and total values.
* Group students by department, city, and gender.
* Assign grades based on marks.
* Rank students using SQL window functions.

## 🛠️ Tools Used

* MySQL
* MySQL Workbench
* SQL

## 📚 SQL Concepts Covered

* SELECT, DISTINCT, WHERE
* ORDER BY, LIMIT, BETWEEN, IN
* LIKE, IS NULL
* Aggregate Functions: COUNT, SUM, AVG, MIN, MAX
* GROUP BY and HAVING
* Subqueries
* CASE Statements
* Date Functions
* Window Functions: RANK(), DENSE_RANK(), ROW_NUMBER(), LAG(), LEAD()
* PARTITION BY

## 📊 Key Analysis

* Identified students based on marks and attendance.
* Calculated average marks by department.
* Found students with fees above the average.
* Categorized students based on their marks.
* Ranked students by marks and within departments.
* Analyzed student records using aggregate and window functions.

## 💡 Learning Outcomes

This project helped me practice SQL querying, data analysis, aggregation, subqueries, and advanced window functions using a student dataset.
